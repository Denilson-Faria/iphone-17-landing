# 📱 iPhone 17 Pro – Product Landing Page

Landing page moderna e responsiva inspirada em páginas de lançamento de produtos premium, desenvolvida com **React** e foco total em **experiência visual, animações e performance**.

![Status do Projeto](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)
![Versão](https://img.shields.io/badge/Vers%C3%A3o-1.0-blue)

---

## 🎯 Objetivo do projeto

O objetivo deste projeto foi recriar uma experiência próxima às **landing pages oficiais da Apple**, explorando:

- Componentização em React
- Animações suaves e reutilizáveis
- Uso de vídeo como elemento principal de destaque
- Layout imersivo e responsivo

Projeto desenvolvido com foco em **portfólio frontend**.

---

## 🚀 Funcionalidades

- Layout totalmente responsivo (mobile e desktop)
- **Hero section imersiva**:
  - Vídeo automático no mobile
  - Imagem otimizada no desktop
- Animações de entrada com componente reutilizável (`AnimatedSection`)
- Seções bem definidas:
  - NavBar
  - Hero
  - Video Showcase
  - Introdução
  - Destaques do produto
  - Cores disponíveis
  - Comparação de modelos
  - Footer
- Navegação clara e fluida
- Estrutura totalmente componentizada

---

## 🧠 Tecnologias utilizadas

- **React**
- **JavaScript (ES6+)**
- **Tailwind CSS**
- **HTML5**
- **CSS moderno**
- **HTML5 Video API**
- **Animações customizadas em React**

---

## 🧩 Conceitos aplicados

- Componentização e reutilização de componentes
- Responsividade mobile-first
- Renderização condicional (mobile vs desktop)
- Performance e otimização de mídia
- UX focado em storytelling visual
- Organização de layout com Tailwind CSS
